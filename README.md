# Chog Fight Club

A 2D/2.5D Chog battle arena prototype.

## Current foundation

- Phaser game engine bootstrapped with Vite
- Fixed side-on arena presentation
- Placeholder chibi Chog rendered from modular body pieces
- Arcade physics with gravity and floor collision
- Left/right movement
- Jumping
- Basic idle/movement/jump squash and stretch
- Fixed battle camera; no explorable world

## Controls

- `A` / `D` or `←` / `→` — move
- `Space` / `W` / `↑` — jump

The placeholder Chog will be replaced by the artist's separated transparent layers once the base Chog artwork is ready.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.
